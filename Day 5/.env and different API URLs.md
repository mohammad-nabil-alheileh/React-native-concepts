# .env and different API URLs

A `.env` file is a text file of `KEY=value` settings that change between environments, such as the API URL. Instead of hardcoding `https://api.myapp.com` in the code, read it from a config value. Switching from dev to stage to prod then means switching which file is used, not editing code.

React Native has no built-in function that reads `.env` files, so you need a library, like `react-native-dotenv`.

## Why you need it

- Dev, stage, and prod each use a different backend URL
- Third-party keys (analytics, maps) differ per environment

For the flavor setup, `react-native-config` is the usual choice.
